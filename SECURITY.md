# Security Policy

## Supported Versions

Security fixes are provided for the latest `0.1.x` release.

## Reporting A Vulnerability

Please report suspected vulnerabilities privately to `office@skyyware.com`.
Include the affected version, reproduction steps, impact and any suggested
mitigation. Do not include customer addresses, credentials or other personal
data, and do not open a public issue before a coordinated fix is available.

Skyyware will acknowledge a report and coordinate validation, remediation and
responsible disclosure with the reporter.
